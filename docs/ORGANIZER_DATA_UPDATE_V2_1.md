## Что поменялось в оценщике

- **Даты:** `action` исключён из temporal recall. Для остальных временных атрибутов проверяются сопоставленные факты, даты которых оценщик считает восстановимыми из транскрипта.
- **Состояния:** исправлена привязка кандидатов к объекту.
- **Факты:** изменены нечёткое сравнение значений, нормализация по каталогу, транслитерация и обработка отрицания.
- **Объекты:** уточнены правила сравнения, разрешено пустое имя, если объект не назван.

По новым пояснениям, если дата не названа, следует возвращать дату звонка. Такие невосстановимые даты исключаются из временной проверки.

## Что мешает просто заменить файлы

1. Текущая схема запрещает пустое `object.name`. Из-за этого она отклоняет новые эталоны в **154 train-звонках и 16 val-звонках**.
2. Новый оценщик требует `started_at` и `turns`. Текущая обвязка расчёта метрик по атрибутам передаёт только `facts` — её нужно адаптировать.
3. Изменение схемы затронет подпись контракта модели. Совместимость с сохранёнными адаптерами нужно обработать явно.

## Найденные проблемы нового пакета

**В новом оценщике обнаружена ошибка:** выражения «через две недели» и «позапрошлый» могут вызвать `TypeError` в функции восстановления дат. Ошибка воспроизведена отдельно. На предоставленном baseline она не возникла; код организаторов не исправлялся.

Внутри вложенного архива `CompactFactExtraction_participants.zip` есть дополнительный **`ANSWERS_v2.md`** с пояснениями. Актуальна его последняя часть — **v2.1**, а не первоначальная таблица v2.
