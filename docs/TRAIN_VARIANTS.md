# Варианты train и подсказки каталога

Три варианта train для обучения на пакете 2.1 и таблица подсказок каталога. В Git
лежит только код: наборы собираются из `train.jsonl` в памяти при запуске обучения,
детерминированно (`--seed`, по умолчанию 42), и на диск не пишутся.

```bash
V=data/organizer/v2_1
python src/train.py --train $V/train.jsonl --val $V/val.jsonl --train-variant noise --check-data
python src/train.py --train $V/train.jsonl --val $V/val.jsonl --train-variant noise --output-dir out/<имя>
```

`--train-variant`: `plain` (по умолчанию, как раньше), `noise`, `resampled`,
`noise_resampled`. Выбранный вариант записывается в `experiment.json`.

Файлы нужны только чтобы посмотреть на данные глазами; они игнорируются Git:

```bash
python src/make_train_variants.py --train $V/train.jsonl --catalog $V/catalog.json \
  --val $V/val.jsonl --output-dir out/train_variants_v21
python src/catalog_hints.py --catalog $V/catalog.json --train $V/train.jsonl \
  --check $V/val.jsonl --output out/train_variants_v21/attribute_hints.json
```

## Наборы

| Вариант (файл) | Звонков | Что внутри |
|---|---:|---|
| `train_noise.jsonl` | 7 852 | каждый звонок чистым и одной шумной копией; уровень шума на звонок — 0,10, 0,20 или 0,30 |
| `train_resampled.jsonl` | 7 074 | каждый звонок и точные повторы выбранных, не больше двух |
| `train_noise_resampled.jsonl` | 11 000 | оба приёма: чистый, шумная копия, шумные повторы выбранных |

В шумных копиях меняется только текст
реплик; факты, даты и реплики-источники остаются эталонными. `call_id` копий получает
суффикс (`~n20`, `~r1`, `~r1n30`), префикс аккаунта сохраняется, пересечения с val нет.
Эпоха на этих наборах длиннее в 1,8–2,8 раза. Бюджет токенов на шумных копиях не
проверялся: нужен токенизатор, `train.py` при превышении остановится сам.

Повторяются 2 250 из 3 926 звонков, по причинам из прогона на V100:

| Причина | Звонков | Что лечит |
|---|---:|---|
| три и более состояний услуги | 366 | recall состояний 0,33 |
| закрытое «работает нормально» и текущий симптом | 771 | смена состояния |
| два и более действий | 1 021 | recall действий 0,28 |
| два и более тарифов | 483 | текущий тариф против прежнего |
| тариф назван рядом со словом «тариф», но факта о нём нет | 884 | не выдавать обсуждаемый тариф фактом |

Доля фактов в `train_resampled.jsonl`: состояние услуги 23,8 % → 26,3 %, действие
20,2 % → 23,7 %, статус заявки 18,9 % → 14,5 %, договорённость 27,2 % → 24,7 %.

## Подсказки каталога

`attribute_hints.json` — записи каталога по атрибутам с ключевыми словами и частотой
в train. `find_hints(call, table)` возвращает для звонка записи, слова которых есть в
тексте; сравнение по началу слова и сходству, эталон не читается.

| Атрибут | Каталожных значений эталона val | Попало в подсказки | При шуме +0,30 | Подсказок на звонок |
|---|---:|---:|---:|---:|
| состояние услуги | 286 | 0,909 | 0,769 | 2,4 |
| тариф | 78 | 0,936 | 0,872 | 4,5 |
| статус заявки | 387 | 0,966 | 0,884 | 1,7 |
| действие | 41 | 0,829 | 0,634 | 0,7 |
| договорённость | 119 | 0,983 | 0,866 | 0,7 |
| имя объекта | 438 | 0,952 | 0,856 | 3,6 |

В запрос модели подсказки не подключены: это меняет контракт запроса и требует
обучения с ними. Поиск занимает около 0,3 с на звонок на CPU.
