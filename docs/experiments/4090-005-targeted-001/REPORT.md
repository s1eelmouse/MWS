## Ограничения и решение

Полный дополнительный noisy-015 для **этих** весов не запускался из-за дедлайна.
Не переносить на v2 результаты шумных проверок родителя. Его noisy S=50.24%
ниже целевого ориентира 51.45%; устойчивость новой версии на таком шуме неизвестна.
Команда выбрала v2 по измеренному росту состояний/источников на исходном val.
Исходная модель сохраняется резервной; никаких новых правил при этой проверке
не включалось. XGrammar, даты, recovery и ограниченная причинная история прежние.

## Приложения

- `evaluations/batch4-001/clean/results/validation/report.json` — исходный полный отчёт;
- там же metrics, predictions/raw, calls/batches, memory.csv и диагностика;
- `evaluations/batch4-001/clean/results/memory-probe/` — отдельная диагностическая
  проверка batch 4, она не подменяет метрики полного val;
- `data-manifest.json`, `run_targeted.py`, `code/` — рецепт, параметры и снимок кода;
- `trainonly-tests.log`, `package-verification.json` — проверки подготовки.

Серверные журналы основного обучения ещё не включены в эту выгрузку:
опубликованные времена/память выше относятся к инференсу. Dataset и веса
в Git-коммит отчёта не включены. Полные веса доставляются через Release.
