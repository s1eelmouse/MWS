## Recovery v2

`src/fact_recovery.py`, политика `explicit-current-per-object-v2`:

- добавляет пропущенный текущий тариф/статус из явной фразы;
- исправляет противоречащий текущий факт, закрывая старый через `valid_to`;
- распознаёт вопросы от первого лица, system-ответы оператора, подтверждения и явную смену тарифа;
- не трогает предложения, планы, отрицания, историю, вопросы без подтверждения и device-упоминания.

На сохранённых предсказаниях 003 та же политика даёт T 0.5092 / S 0.5201. На свежей генерации T ниже (0.4807), потому что это другой набор ответов и у 24 val-звонков изменены входные поля; S совпала.
