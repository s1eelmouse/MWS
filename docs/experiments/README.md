# Документация обучающих экспериментов

Сводный человекочитаемый отчёт по всем циклам: [TRAINING_REPORT.md](../TRAINING_REPORT.md).

| Цикл | Содержание |
|---|---|
| [4090-baseline-001](4090-baseline-001/README.md) | Первая эпоха QLoRA: отчёт, приложения и диагностика 22 отказов |
| [4090-continue-002](4090-continue-002/README.md) | Дополнительная эпоха: алгоритм, сценарий, отчёт, метрики и исследовательский анализ |
| [4090-continue-003-v2](4090-continue-003-v2/README.md) | Свежий полный val 2.1 на 4090: `003` + recovery v2, clean T 0.4807 / S 0.5201, noisy T 0.4582 / S 0.4141, 0 отказов |

Для каждой следующей тренировки создавать отдельную папку с её experiment_id.
В каждой текущей папке есть code/src и code/tests — снимки использованных версий,
code-manifest.json — происхождение и хеши, replay.sh — новый сценарий повторения
обучения, merge и оценки; режим test запускает программные тесты.
Для второго цикла отдельно сохранён подлинный run-continue-002.sh.
В ней хранить README-оглавление, алгоритм/параметры, сценарий запуска, итоговый отчёт
и компактные приложения с контрольными суммами. Отделять фактический результат от
последующих исследовательских обработок и указывать сравниваемую версию.

Веса, состояния оптимизатора, исходные данные и сырые генерации хранить вне Git.
Общие правила сервера и измерений остаются в docs/SERVER_HANDOFF.md и docs/MEASUREMENTS_4090.md.
Общие таблицы нескольких вариантов остаются в docs/RESULTS.md.
Исторические code-снимки не переписывать при следующих доработках: изменения делать
в общих src/tests, затем фиксировать новую папку эксперимента.
