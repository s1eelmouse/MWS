# 005 → одна обычная эпоха train 2.1

Эксперимент `005-plain-epoch-001` завершён на RTX 4090. Полный чистый val 2.1:
383 звонка, 0 отказов, 100% валидных ответов. Это отдельный кандидат;
исходная 005 остаётся резервной моделью. Шумная проверка новой модели выполняется
отдельно и в этот комплект не входит.

| Модель / одинаковые общие правила | Precision | Recall | Даты T | Состояния S | Источники G |
|---|---:|---:|---:|---:|---:|
| База организаторов | 0.3348 | 0.3805 | 0.4706 | 0.5345 | 0.7835 |
| Исходная 005 | 0.5415 | 0.5805 | 0.5061 | 0.5602 | 0.7824 |
| 005 + одна обычная эпоха | 0.5073 | 0.5821 | 0.5152 | 0.5602 | 0.7924 |

Результат смешанный: даты и источники улучшились, precision снизился,
состояния в целом не изменились. Сравнение 005 с общими правилами получено
пересчётом сохранённых ответов; скорость двух моделей в одинаковом окружении
не измерялась. Обучение: 39 мин 25 с; измеренная генеративная проверка:
58 мин 22 с. Подробности и ограничения — в [REPORT.md](REPORT.md).

## Состав опубликованного комплекта

- [REPORT.md](REPORT.md) — методы, параметры, результаты, ресурсы и выводы.

- [results/validation/report.json](results/validation/report.json) и
  [metrics.json](results/validation/metrics.json) — исходные серверные отчёты.
- `results/validation/` — raw-answers, predictions до/после истории, calls,
  batches, memory.csv, temporal-audit, ошибки и окружение.
- `results/adapter/` — параметры нового LoRA, loss-history, события,
  контекст обучения, версии пакетов и статистика памяти.
- `results/` — логи стадий, настройки, статусы, сравнение и проверка выгрузки.
- `run-005-plain-epoch-001.py`, `Start-005PlainEpoch.ps1`,
  `Download-005PlainEpoch.ps1`, `Extract-005Results.py` — использованные сценарии.
- `code/` — замороженный код `case-v21-unified-001`, использованный экспериментом.
  Он хранится для воспроизведения и не подменяет рабочий код в корне проекта.
- [PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json) — SHA256 и размеры
  всех файлов этого опубликованного комплекта (кроме самого манифеста).

Веса, бинарные checkpoint-файлы, архив выгрузки и исходные train/val/catalog
в Git не включены. Полные локальные артефакты сохранены отдельно в MWS;
ссылки на них — `results/LOCAL_ARTIFACTS.json`. Эти пути относятся к компьютеру
автора и не обязаны существовать у других участников.

## Воспроизведение

Фактические параметры и пути записаны в `results/settings.json`,
`results/adapter/experiment.json` и `results/validation/environment.json`.
Одна эпоха, свежие LoRA и оптимизатор поверх merged 005, LR=3e-5, seed=42,
microbatch=1, accumulation=16, 246 шагов. Val не участвует в градиентах.

Снимок `code/` нужно развернуть как серверный release
`~/mws-v21/releases/case-v21-unified-001`, отдельно восстановить исходные
данные по контрольным суммам `source-release-manifest.json` и родительскую
merged 005 в `~/mws-v21/models/005-noise-20261115`. В manifest снимка также
есть ссылки на шумный набор для другого сценария; данные намеренно исключены
из Git. Не запускать сценарии поверх существующего результата с тем же ID:
использовать отдельную рабочую директорию и новый ID эксперимента.
PowerShell-сценарии сохраняют исторические пути автора; перед использованием
на другом компьютере их нужно настроить под свой ключ, Python и папки.
