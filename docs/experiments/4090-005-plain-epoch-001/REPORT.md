# 005 → одна обычная эпоха 2.1: результаты

16 ноября 2026. Эксперимент `005-plain-epoch-001` завершён. Полный clean val 2.1,
383 звонка, 1845 эталонных фактов. Отказов нет, валидность формата 100%.

**Вывод:** эффект дополнительной эпохи есть, но общего превосходства над 005 нет.
Даты и реплики-источники улучшились, услуги стали определяться чаще, однако
состояния тарифов/заявок ухудшились, а precision снизился. Исходная 005 остаётся
проверенной резервной основой; новая модель — отдельный кандидат. На шумном val
новая модель ещё не проверялась. Ещё одну обычную эпоху эти результаты не обосновывают.

## Главное сравнение

Проценты. «005» здесь означает выбранную основу с общими правилами, а не её
исходный старый recovery и не экспериментальный services-001.

| Метрика | Организаторы | 005 + общие правила | После ещё одной эпохи | Изменение к 005 |
|---|---:|---:|---:|---:|
| Precision | 33.48 | **54.15** | 50.73 | −3.42 п.п. |
| Recall | 38.05 | 58.05 | **58.21** | +0.16 п.п. |
| Temporal recall | 47.06 | 50.61 | **51.52** | +0.91 п.п. |
| State accuracy | 53.45 | **56.02** | **56.02** | 0 |
| Grounding turn | 78.35 | 78.24 | **79.24** | +1.00 п.п. |

Новая модель выше опубликованной базы организаторов по всем пяти показателям.
При целях T≥45.06%, S≥51.45% запас на этом clean val: **+6.46 и +4.57 п.п.**
Правильных состояний 349/623, для порога нужно 321: запас 28 состояний.
Из этого не следует наличие такого же запаса на скрытых/шумных данных.
У исходной 005 с общими правилами noisy S=.4944, ниже цели; у новой noisy неизвестен.

Прежняя наша `4090-continue-v21-001` со статусными правилами имела
P=.5126, R=.5409, T=.5049, S=.5297, G=.7856. Новая модель выше её по R/T/S/G,
но немного ниже по P. Для выбора между текущими кандидатами основной контроль — 005.

Было 1978 предсказаний / 1071 сопоставление / 907 лишних; стало
2117 / 1074 / 1043. Recall почти не изменился, потому что добавилось только
три сопоставления. Большая часть роста лишних предсказаний — договорённости:
precision .2899→.2554, recall .5586→.5418. Простое продолжение обучения не решило
различение фактической договорённости и других реплик. Это не доказательство
«модель зазубрила val»: для такого вывода данных нет.

По временным парам: 330/652→338/656. Дат стало правильно больше на восемь,
но метрика условна по сопоставленным фактам. Grounding также условен; сравнение
его процента не равно проверке источников каждого возможного факта.

## Выбор и дальнейшие шаги

Новую модель нельзя назвать однозначно лучшей: T/G выросли, P снизился,
S тот же, а шум не измерен. Пока сохранить исходную 005 как резервную основу;
новые веса не удалять и не подменять ими финальный артефакт автоматически.

Следующее полезное сравнение — **один полный noisy val новой модели** при том же
конвейере, без ещё одного обучения. Если он хуже по состояниям, аргументов
выбирать новую модель существенно меньше. Если лучше, решение зависит от
приоритетов метрик и допустимого роста лишних фактов.

Для адресного дообучения есть конкретное направление: услуги/объекты/текущие
состояния с сохранением примеров тарифов и заявок, плюс отрицательные примеры
договорённостей. Всё брать из train; val не переносить в обучение. Одна обычная
эпоха дала смешанный эффект, но это не доказывает бесполезность других рецептов,
другого LR, промежуточного checkpoint или адресной выборки.
