## Звонок с относительными датами

Сохранить в `/tmp/demo.json`:

```json
{
  "call_id": "demo:relative-dates",
  "started_at": "2026-03-11T10:00:00",
  "turns": [
    {"idx": 0, "speaker": "client",
     "text": "Вчера пропал интернет, а со вторника не работает телевизор."},
    {"idx": 1, "speaker": "operator",
     "text": "Заявку приняли сегодня. Мастер приедет в пятницу после двух."},
    {"idx": 2, "speaker": "client", "text": "Да, в пятницу подходит."}
  ]
}
```

```bash
curl -fsS -X POST http://127.0.0.1:8000/extract \
  -H 'Content-Type: application/json' --data-binary @/tmp/demo.json
```

Что показать в ответе:

- `service_state` «нет доступа в интернет» → `valid_from = 2026-03-10`;
- `ticket_status` «принята» → `valid_from = 2026-03-11`;
- `agreement` «выезд специалиста» → `valid_from = 2026-03-13`;
- `source.turn_idx` — исходная реплика, не позиция в массиве.

Точный набор фактов зависит от модели; на защите комментируем даты и источники,
а не обещаем дословный JSON. Если модель вернула меньше фактов — это ожидаемо
для 0,6B, показываем то, что есть, и переходим к метрикам полного val.

- `format_valid_rate = 1.0`, `failed_calls = 0`.

Шумный val 2.1 для `003 + recovery v2`: T 0.4582 / S 0.4141, 0 отказов,
формат 100 %. T проходит цель, S — нет; `005` на шуме обучена (чистый val T 0.4900 / S 0.5522), её шумный val ещё считается. Старые
шумные числа относятся к пакету 1 и на защите не показываются как финальные.

Важно: пакетный результат с переносом серий не равен HTTP-ответу на один звонок.
Для демо одного звонка это нормально; не приписывать HTTP-сервису пакетные 0.4807.

## Раскадровка и текст (2:30)

| Время | Что на экране | Что говоришь |
|---:|---|---|
| 0:00–0:20 | терминал, `curl /health` | «Сервис поднят: модель загружена, constrained JSON включён, отказов нет». |
| 0:20–0:50 | `/tmp/demo.json` без `facts` | «Синтетический звонок: вчера, со вторника, сегодня, в пятницу. Эталонных фактов в запросе нет». |
| 0:50–1:30 | ответ `/extract` | «Дата звонка 11 марта. Вчера — 10-е, со вторника — 10-е, сегодня — 11-е, пятница — 13-е. У каждого факта source — реплика-источник». |
| 1:30–2:00 | `report.json` | «Свежий полный val 2.1: 0 отказов, 100 % формата. T 0.4807, S 0.5201; обе цели достигнуты». |
| 2:00–2:30 | слайд 7 или терминал | «Ограничения: скрытый adversarial не проверен, первая половина val по S ниже цели, на шумном val S 0.4141 — ниже цели. Поэтому модель не фиксируем по одному прогону». |

Не показывать в кадре gold `facts`, внутренние пути сервера и ключи. Если
ответ пришёл неполным — не перезаписывать видео «до победного», а показать
честный ответ и перейти к `report.json`.
