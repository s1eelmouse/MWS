# Происхождение копии и восстановление

Источник: https://github.com/s1eelmouse/MWS
Просмотренная upstream-версия: dee688c117ed423c6543d80fc58a03442e527379.

При первоначальной подготовке на ноутбуке был авторизован браузер,
но командный Git не был авторизован. Поэтому исходники были получены
штатной кнопкой Download ZIP через GitHub.
Это НЕ полноценный клон истории GitHub. Создана отдельная локальная история
точного исходного снимка; её нельзя выдавать за исходную историю репозитория.

Начальный локальный коммит сохраняет исходный снимок. Ветка upstream-snapshot
и тег backup/upstream-dee688c удерживают его. Изменения делаются в ветке
codex/compactfact-adaptation. На этом этапе исходный GitHub-репозиторий
не изменялся.

После авторизации Git безопасный способ переноса:
1. Получить настоящий клон upstream в другой папке.
2. Создать там отдельную ветку.
3. Применить подготовленные format-patch файлы, исключающие исходный снимок.
4. Запустить тесты, проверить diff, затем отправить новую ветку.
Не заменять main снимком с несвязанной историей и не применять force push.
